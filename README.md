# AI 工作猎手

AI 工作猎手运行在 BOSS 直聘网页中，可辅助阅读职位信息、判断岗位是否适合、生成岗位化招呼语、发送简历、回复 HR 消息，并在出现高意向沟通时提醒本人处理。

## 一、开始前准备

请准备以下内容：

- Chrome 或 Edge 浏览器；
- 可以正常登录的 BOSS 直聘账号；
- 一份 PDF 或 DOCX 附件简历；
- 一个用于接收提醒的邮箱。

## 二、安装脚本管理器

新用户推荐使用 [ScriptCat](https://scriptcat.org/)。已经使用 Tampermonkey 的用户可以继续使用现有管理器。两者选择一个即可，同一份脚本只安装一份。

安装完成后，请在浏览器扩展管理页面确认脚本管理器已启用。

## 三、安装 AI 工作猎手

打开[脚本安装链接](https://aijob.zxpnb.top/ai-job-hunting.user.js)，在脚本管理器的确认页面点击“安装”。当前正式脚本版本为 `0.0.95-greeting-log-fix`。

安装完成后：

1. 打开脚本管理器；
2. 搜索“AI 工作猎手”；
3. 确认只启用一份脚本；
4. 关闭旧版、测试版和重复脚本。

### 免费内测

当前版本开放免费内测。首次登录后，在“内测激活”窗口输入管理员提供的激活码，即可获得全功能 7 天体验。激活时间从该 BOSS 账号首次成功激活开始计算；同一个 BOSS 账号只能使用一次，过期后不能重复使用同一内测码。激活码不会写入脚本或 GitHub 仓库。

## 四、打开 BOSS 页面

打开 [BOSS 直聘](https://www.zhipin.com/) 并登录，进入职位搜索、职位推荐或消息页面，然后刷新页面。右侧出现“AI 工作猎手”面板后，继续下一步。

安装确认页面只用于安装脚本，不会显示 AI 工作猎手面板。面板只会出现在 BOSS 职位或消息页面。

## 五、首次设置

请严格按照以下顺序操作：

1. 在 BOSS 中上传 PDF 或 DOCX 附件简历；
2. 回到职位或消息页面并刷新；
3. 点击“连接测试”，确认连接状态正常；
4. 点击“导入简历”，等待导入成功；
5. 打开“偏好设置”；
6. 手机号和通知邮箱均可留空；需要邮件提醒时再填写通知邮箱；
7. 填写求职城市、岗位方向和薪资范围；
8. 开启“AI 过滤（语义匹配）”；
9. 保存偏好设置；
10. 先使用一个职位测试投递；
11. 确认投递记录正常后，再开启 AI 坐席。

导入功能用于生成岗位化招呼语和 HR 回复，仍需先完成 BOSS 自身的附件简历上传。更换 BOSS 附件简历后，需要重新导入。

## 六、偏好设置

### 6.1 通用风险识别

系统会把完整职位描述、公司信息、薪资、地点、任职要求、当前账号简历和已启用的求职偏好交给 AI 逐职位分析。固定风险词不再在 AI 之前直接过滤，单个词不能单独决定结果；只有完整语境明确显示高风险或严重不匹配时才会过滤。

用户无需维护这套基础策略，只需填写自己的求职方向和实际要求。

### 6.2 手机号和通知邮箱

当前版本保存偏好时不要求填写这两个字段：

- **手机号**：可选，仅用于个人档案信息；当前自动沟通内容不会把它作为发送内容。
- **通知邮箱**：可选，仅在需要接收高意向、面试和异常提醒时填写；清空后会同步清除服务端邮箱。

只从页面删除手机号输入框，仍会触发表单校验或账号识别问题。手机号改为可选需要同步调整账号标识、简历导入、数据保存和历史数据迁移，属于后续版本工作。

### 6.3 偏好填写示例

可以直接粘贴下面的内容，再把方括号中的文字替换成自己的情况：

```text
我希望在【目标城市】及周边寻找工作，优先选择通勤合理的岗位。
我愿意尝试 AI 工具辅助、内容运营、资料整理、数据处理、内容质检、基础测试、运营助理、项目助理、行政文员和客服支持等工作。
经验要求可以放宽到应届生、在校生、无需经验或有人带教的岗位。
期望薪资为【薪资范围】，请结合岗位实际情况判断。
请结合完整职位描述、公司信息、薪资、地点、任职要求和 HR 信息进行综合判断。
```

首次设置建议：

| 设置 | 建议 |
| --- | --- |
| 简历/现居城市 | 填写简历上的真实城市 |
| 本轮目标城市 | 填写本轮实际求职城市 |
| 地区一致性保护 | 开启，发现搜索城市与岗位地点异常时暂停提醒 |
| AI 过滤（语义匹配） | 开启，由 AI 逐个阅读职位和公司信息 |
| 公司、职位包含/排除 | 首次可以留空 |
| 薪资范围 | 按实际目标填写，并确认月薪或日薪单位 |
| AI岗位化招呼语 | 首次关闭；开启后 AI 根据当前岗位和简历生成，可在“招呼语补充要求（可选）”里补充表达偏好 |
| 高意向暂停 AI 坐席 | 开启，面试和联系方式推进交给本人确认 |
| 通知邮箱 | 需要接收人工确认提醒时填写；不填写则不发邮件 |

高意向不是按固定关键词或聊天轮数判断。开启相关功能后，系统会把岗位信息、当前账号的简历、求职要求、已有对话和本轮双方消息交给 AI 做结构化复核；只有 AI 给出高置信度的匹配与推进结论，才会标记为高意向。面试、电话、微信、地点和其他关键决定仍会直接交给本人确认。

## 七、搜索和投递

先使用 BOSS 自带搜索扩大候选范围，再由 AI 阅读完整职位信息。可以分别搜索：

- AI 应用助理、AI 产品助理、智能工具运营；
- AIGC 内容、短剧内容、素材整理、内容运营；
- 资料整理、数据处理、信息录入、内容质检、基础测试；
- 运营助理、项目助理、行政助理、文员、客服支持；
- Excel、表格处理、知识库维护、流程跟进、办公自动化助理。

第一次投递只测试一个职位：

1. 打开职位右侧的完整详情；
2. 确认地点、薪资单位、工作内容、公司介绍和任职要求正常显示；
3. 确认连接在线、简历已导入、偏好已保存；
4. 将单次投递数量设置为 `1`；
5. 点击“开始投递”；
6. 查看岗位判断通知和右下角运行记录；
7. 确认记录中同时有 AI 结论、简要原因和实际发送状态。

“分析成功”或“招呼语生成成功”只代表分析或生成完成，最终状态以 BOSS 页面实际发送回显和运行记录为准。

## 八、AI 坐席

开启顺序：

1. 确认面板显示连接正常；
2. 在 AI 助手页面开启 AI 坐席；
3. 保持 BOSS 消息页处于登录状态；
4. 在消息页面观察回复和运行记录。

AI 坐席依赖当前打开的 BOSS 页面、浏览器脚本和消息连接。页面刷新、账号切换、浏览器休眠或连接中断后，请刷新页面并重新连接；必要时点击“重启当前会话 AI 坐席”。

以下事项会提醒本人确认：

- 面试日期、时间、地点和会议链接；
- 手机号、微信或其他联系方式交换；
- 薪资承诺、到岗日期、试用期和录用确认；
- 要求付款、提供证件、下载未知软件或进行账号验证。

## 九、邮件提醒

用户只需在偏好设置中填写接收邮箱并打开相应提醒。

高意向邮件用于提醒查看岗位和会话内容，不替代本人确认。收到面试或联系方式推进提醒后，请先查看职位详情、公司信息和完整聊天记录，再决定下一步。

## 十、日志和投递记录

- **右侧岗位判断通知**：显示当前岗位的 AI 结论、简要原因和建议动作；
- **右下角运行记录**：显示投递、招呼语生成、发送确认、失败重试和 AI 坐席事件。

两处显示的是同一套运行记录，区别只在展示位置和重点，不会产生两次投递。

| 状态 | 含义 |
| --- | --- |
| 岗位通过 | AI 判断岗位符合当前方向，可以继续尝试 |
| 岗位过滤 | AI 判断岗位质量、风险或匹配度不适合，停止该岗位 |
| 需要人工确认 | 信息不足或涉及关键事项，等待本人处理 |
| 招呼语生成成功 | 已生成岗位化首句，尚未代表 BOSS 发送成功 |
| 发送确认 | BOSS 页面确认消息已提交 |
| 发送失败 | 页面状态或 BOSS 提交未完成，可根据记录重试 |

## 十一、常见问题

### 面板没有显示

确认脚本管理器已启用，关闭旧版和重复脚本，打开 BOSS 职位或消息页面并刷新。当前脚本版本应为 `0.0.95-greeting-log-fix`。

### 内测激活提示

首次进入且尚未拥有有效权益时会自动显示内测窗口。请在“内测激活”窗口输入激活码；激活成功后立即获得 7 天全功能体验。

### 只看到脚本源码

确认 ScriptCat 或 Tampermonkey 已启用，然后重新打开[脚本安装链接](https://aijob.zxpnb.top/ai-job-hunting.user.js)。该地址需要交给脚本管理器处理。

### 连接测试失败

确认 BOSS 已登录且浏览器可以打开安装页。若曾经手动修改过服务地址，使用面板中的重置按钮恢复默认设置，然后再次连接测试。

### 导入简历一直等待

确认 BOSS 附件简历已经上传完成，刷新 BOSS 页面后再次点击导入。登录状态失效或连接中断时，需要重新登录并连接。

### AI 坐席没有回复

确认 AI 坐席仍处于开启状态，检查当前会话是否因人工回复而暂停，再查看运行记录中是否有发送失败、连接中断或人工确认状态。必要时刷新页面并重启当前会话坐席。

### 更新后出现两个脚本

打开脚本管理器，禁用或删除旧版，只保留当前版本。更新时始终使用同一条[脚本安装链接](https://aijob.zxpnb.top/ai-job-hunting.user.js)，不要新建脚本再粘贴代码。

## 十二、更新方式

每次更新按以下顺序操作：

1. 打开[脚本安装链接](https://aijob.zxpnb.top/ai-job-hunting.user.js)；
2. 在脚本管理器中选择更新当前脚本；
3. 确认只保留一份 AI 工作猎手；
4. 回到 BOSS 页面并刷新；
5. 检查面板版本、连接状态和 AI 坐席状态；
6. 先用一个职位验证，再恢复日常使用。

日常使用只需要记住两个入口：[AI 工作猎手安装页](https://aijob.zxpnb.top/install.html)和 [BOSS 直聘](https://www.zhipin.com/)。
