# 后端开发

Spring Boot 3、JDK 17、MyBatis Plus、MySQL 与 Spring AI。处理岗位判断、简历文本、HR 回复、会话状态和人工接管。

这是开发与受控试用说明，不是已经验证的一键生产部署方案。

## 测试与打包

```powershell
mvn test
mvn -DskipTests package
```

`EmailTest` 会启动应用并涉及数据库/邮件；`JobAgentTest` 会调用本地 HTTP 服务。它们默认跳过，避免意外连接真实服务。只有配置好隔离的测试数据库、测试邮箱和本地服务后，才运行 `mvn test -Drun.integration.tests=true`。只有依赖已缓存时才添加 `-o`。

当前 POM 依赖 Spring AI `0.8.1-SNAPSHOT`。本机缓存中的成功构建不能证明陌生开发者可以从零下载该历史快照；干净机器依赖验证是发布前门槛，不要直接升级后宣称兼容。

## 本地配置

1. 准备 MySQL，创建 `ai_job` 数据库，将 `src/main/resources/schema.sql` 导入开发库。不要对现有生产库直接执行建表脚本。
2. 将 `src/main/resources/application.example.properties` 复制为 `src/main/resources/application.properties`；后者被 Git 忽略。
3. 在环境变量中设置数据库用户名、密码、模型 Key 和 SmartConfig 管理密码。模板不含真实凭据，也没有免密管理配置。
4. 根据模板保留模型池、免登录入口和权限配置。`admin.userId.list=[]` 不会把第一个用户默认设为管理员。
5. 构建后运行：

```powershell
java -jar target/ai-job.jar
```

默认只绑定 `127.0.0.1:9100`，不自动公开互联网端口。BOSS 为 HTTPS 页面，真实网页联调需自行配置可信 HTTPS 反向代理和 CORS；不要直接假设网页可访问明文 localhost 服务。

候选流程在用户主动成功导入简历后自动授予 BETA 全功能权限，统一有效至 `2026-12-30T23:59:59.999+08:00`。这是一个可配置的内测截止时间：

```properties
BETA_AUTO_GRANT_UNTIL=2026-12-30T23:59:59.999+08:00
```

留空可以关闭自动授权。截止时间之后不再发放内测权益；本版本不提供激活码入口。若实例维护者需要延长开放期，应明确修改配置并自行承担权限、数据和平台规则审查责任。

导入前端会从已登录的 BOSS 页面获取附件并上传到后端；后端保存解析后的简历文本，部分文件可能发送给部署者配置的模型服务。项目当前没有自助删除账号和关联数据的 API。公网实例不要开放给真实用户，直到数据保留/删除、用户自定义 API 出网限制、滥用限速和费用上限均已落实。

候选代码的用户自定义模型直连路径会拒绝 URL 凭据、查询参数、非 HTTPS 地址和环回/私网 IP；DNS 连接阶段会再次检查解析结果，并禁用 HTTP 重定向。模型响应限制为 2 MiB，请求超时限制为 1 至 120 秒。开发者自建本机模型时，只有在隔离的本机环境中才可显式设置 `AI_CUSTOM_API_ALLOW_PRIVATE_ADDRESSES=true`；HTTP 模型端点还需单独设置 `AI_CUSTOM_API_ALLOW_INSECURE_HTTP=true`。这两个开关不应用在共享或公网实例。

管理员配置的全局模型池若启用代理，会经 `proxy_host` 出站；目标地址解析由代理负责，不经过应用内的目标 IP 校验。只应使用可信代理，并在代理和服务器网络层限制私网、环回及云元数据地址。

候选服务还对简历导入、静默登录、模型配置测试、岗位筛选、岗位化招呼和 AI 对话设置了单实例频率限制，并限制并发模型请求。免登录入口还有独立于请求 UID 的路由总限速。它们不是分布式限流，也不是每日费用上限；公网部署仍需由可信反向代理覆盖客户端地址头，配置 WAF/出口规则，并在模型供应商侧设置账单告警或额度。

用户配置查询不会返回已保存的 API Key。保存设置时，空白 Key 默认表示“保留现有密钥”；只有显式传入 `clearApiKey=true` 才会清除。

生产数据库升级前，请先按项目迁移说明检查 `user_product` 中重复的 BETA 自动授权记录，再建立专用幂等唯一索引。不要直接对已有生产库重复执行完整建表脚本。当前版本暂不提供付费服务；支付宝接口和定时订单任务默认关闭，支付代码仅保留为未启用模块。

`/test/**` 模型调试接口默认不加载。只有在隔离的开发环境中显式启用 `test-endpoints` profile 才会注册，不能把这个 profile 用在公网实例。

## 邮件与支付

邮件默认读取工作目录 `config/mail.setting`，也支持 JVM 参数 `-Dai.job.mail.setting=...` 或环境变量 `AI_JOB_MAIL_SETTING` 指定外部文件。未配置 SMTP 时不能声称邮件通知可用。不要设置全局 `notifyTo` 收集其他用户的会话内容。

支付宝代码仍在仓库中，但 `payment.enabled=false` 时不会注册支付控制器和服务，也不会启动支付订单定时任务。当前不要为了测试自动内测而启用支付。

## 公开服务门槛

单元测试通过并不证明公网多用户服务安全。还需复核身份验证在第三方接口异常时的策略、测试/管理入口、速率限制、数据保留与删除、模型数据传输、依赖与许可，以及真实 BOSS 验收。

本次归档移除了依赖特定宿主网络、特权容器和公开管理端口的旧 Docker 示例。新的容器部署方案应在干净环境验证后再加入，避免把旧示例当成受支持方案。
