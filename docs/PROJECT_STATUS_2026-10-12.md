## 用户流程修正

目标流程已明确为：登录 BOSS -> 服务端核验 BOSS UID 与 token -> 自动创建空用户档案 -> 开放期内自动开通内测权限至 **2026-12-30 23:59:59.999（中国标准时间）**。整个登录和激活过程不读取简历。

简历导入是另一个独立步骤：只有用户主动点击“导入简历”后才读取并上传，用于需要个人经历的功能。它不是创建账号或开通内测权限的条件。

## 已部署改动

- `UserService.loginSilently()` 在身份核验后以事务创建或读取账号，并自动调用幂等内测授权。
- 并发授权遇到唯一键冲突时改用 `FOR UPDATE` 当前读找回已提交的权益行，避免使用旧事务快照导致简历导入偶发回滚。
- 并发首次登录依赖 `user_info.unique_id` 唯一索引；遇到唯一键竞争会回滚后重新读取胜出账号。生产库已核验存在 `uk_user_info_unique_id`。
- CORS 白名单加入精确来源 `https://www.zhipin.com`；合法预检请求直接返回 200，不再继续进入业务路由，并覆盖伪造相似域名和预检短路测试。
- 前端、偏好默认值、权益面板、帮助文档已改成自动建档/激活口径。旧服务端若仍返回“用户不存在”，会提示这是服务端未更新，不再让用户误以为必须上传简历。
