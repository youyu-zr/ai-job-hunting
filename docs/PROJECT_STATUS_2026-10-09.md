# 项目状态：2026-10-09

## 当前结论

公开 GitHub 仓库已经存在，但公开主分支仍是旧版激活流程。线上安装入口与后端已于 2026-10-09 部署 `0.0.113-beta-auto-grant`；自动授权已启用、付费已关闭，但本次源码尚未提交或推送。项目还没有完成真实 BOSS 账号端到端验收，不能宣传为无风险的大规模自动投递工具。

当前产品口径：

> 运行在 BOSS 直聘网页中的开源 AI 求职副驾。首次成功导入简历后自动获得全功能内测权限，有效至 2026 年 12 月 30 日 23:59:59（中国标准时间）。当前版本暂不提供付费服务。

## 本轮已完成

- 自动内测授权只在简历成功保存后触发。
- 内测授权固定使用 `order_id = -2`，同一用户重复导入、刷新和查询不会重复创建。
- 较短的自动授权会延长到统一截止时间；更晚的有效期不会被缩短。
- 历史其他 BETA 订单不会被自动授权逻辑覆盖。
- 截止时间使用带时区的 ISO-8601 配置，默认值为 `2026-12-30T23:59:59.999+08:00`。
- 前端已经删除激活码输入框和手动激活请求。
- 支付控制器和订单服务默认不加载，`payment.enabled` 默认关闭。
- 自动授权唯一性使用只针对 BETA 自动授权行的生成列唯一约束，避免影响邀请兑换。
- 内部工程已同步授权、支付开关、数据库结构和前端权限面板。
- 旧的七天体验宣传素材已更新为自动授权和开源协作口径；旧成片仅作为历史草稿，不应继续发布。
- 线上安装页、用户脚本和后端 JAR 已与本地发布产物逐项哈希核对一致；后端启动成功并连接数据库。
- 本次未执行数据库结构迁移，也未改 Nginx 配置；现有数据库索引约束保持原样。
- 后端单实例重启造成约 49 秒 API 冷启动窗口；Nginx、MariaDB、Redis 均持续正常。
- 唯一回滚包保存在维护者受控的线上目录，不在公开文档中披露服务器路径；临时旁路进程、端口与防火墙规则已清理。

## 现在可以怎么用

建议仅用于：

- 本人 BOSS 账号；
- 单账号；
- 单个低风险岗位；
- 单次发送数量设为 1；
- 用户在场检查生成内容和页面回显。

暂不建议：

- 无人值守批量投递；
- 自动交换电话、微信或其他联系方式；
- 自动确认面试、薪资、到岗或录用；
- 把陌生用户直接导入同一个未完成回滚演练的托管实例；
- 在没有脱敏和授权的情况下提交真实简历、聊天记录或 Cookie。

## 公开协作入口

优先欢迎以下类型的 Issue/PR：

1. 脱敏岗位样本和消息解析回归测试；
2. BOSS 页面兼容性记录；
3. UI 错误态、加载态和权限提示改进；
4. Docker、数据库初始化和干净机器启动文档；
5. CI、日志脱敏和测试覆盖；
6. 发送状态、人工暂停和账号隔离的回归测试。

涉及真实账号、生产 Cookie、支付凭据、数据库密码、模型 Key、真实简历或未脱敏聊天记录的内容，不进入公开仓库。

## 2026-10-10 对抗性复核补充

只读检查线上安装入口发现：其返回脚本仍为 `0.0.113-beta-auto-grant`，新用户静默登录分支会自动调用简历导入，下载并上传附件简历；这与本地源码和此前宣传所称的“用户主动点击导入”不一致。因此暂停向新用户推广当前安装入口。

本地准备版本已改为 `0.0.114-beta-consent`，并在安装页禁用下载入口；它尚未部署。后端新增的事务写入、UID 唯一索引和测试修正也仅存在本地。公开发布仍被自定义模型地址 SSRF、共享服务限流/费用上限、许可证来源核验、现有数据库迁移评估和真实 BOSS 全流程验收阻断。
