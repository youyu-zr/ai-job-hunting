# 真实账号验收清单

状态：未完成。合成测试、页面截图和后端打包不等于此清单通过。必须由账号本人操作，不收集 Cookie 或他人真实聊天。

## 前置条件

- [ ] 只启用一份脚本，核对版本、namespace 与后端地址。
- [ ] 由维护者核对 BOSS 当前有效平台协议及第三方脚本/自动收发消息授权边界；未确认前不扩大公开分发。
- [ ] 使用本人账号登录并确认自动建档；若使用简历功能，再主动导入本人简历并核对事实、城市与偏好。
- [ ] 单次数量为 1，选择低风险且信息完整的岗位，本人在场。
- [ ] 知道如何立即关闭脚本和暂停 AI 坐席。

## 业务流程

- [ ] 无简历用户首次登录时，身份核验通过后自动创建空账号并开通有效期内的内测权限。
- [ ] 首次登录流程不读取或上传简历；只有用户主动点击“导入简历”后才上传。
- [ ] 无简历时投递入口会清楚提示先在 BOSS 上传本人附件简历并导入；投递不会开始。
- [ ] 无简历时开启 AI 坐席会清楚提示先导入；关闭 AI 坐席仍然可用。
- [ ] 导入简历成功后，岗位化首句基于当前简历和岗位生成；缺简历的后端请求不会调用模型。
- [ ] 单次投递默认上限为 5，用户可调整至 1-100。
- [ ] 聊天页不显示批量发送入口；单个当前会话仍可由用户恢复。
- [ ] 同一 BOSS UID 并发首次登录最终只创建一个账号；确认数据库存在 `uk_user_info_unique_id`。
- [ ] 确认生产 `user_product` 存在 `uk_beta_auto_grant_user` 或兼容的 `uk_beta_user`，并发登录/导入不会重复发放 BETA 权益。
- [ ] BOSS 身份核验失败时，不创建账号、不发放权限、不返回会话。
- [ ] 筛选理由与岗位详情一致；缺失重要信息时不盲投。
- [ ] 岗位化首句不编造履历，不追加 BOSS 固定招呼语。
- [ ] 目标会话出现一条己方消息，记录正确区分提交与确认。
- [ ] 确认超时/网络中断时不盲目重复发送。
- [ ] 普通 HR 文本回复进入正确会话，回答不编造候选人事实。
- [ ] 用户手动回复后只暂停当前会话，生成中的旧回复不得补发，其他会话继续按自己的状态运行。
- [ ] AI 坐席总开关关闭时，实时消息和断线期间积压的消息都不自动回复。
- [ ] AI 坐席总开关关闭时，断线补扫不会打开 HR 会话、触发已读或读取积压消息。
- [ ] AI 坐席总开关开启并重新登录后，最后一条确实来自 HR 且用户没有后续回复的消息可以继续处理。
- [ ] 未选中联系人只有在 BOSS 联系人数据明确显示最后发送者 ID 与目标 HR 一致时才补扫；发送者缺失或 ID 不一致时跳过，不打开其他联系人。
- [ ] 如果最后一条由用户本人发送，即使联系人仍有未读标记，也不会重复回复。
- [ ] 同一 HR 连续积压多条消息时，合并上下文后只发送一次回复。
- [ ] 点击“恢复本会话自动回复”后，当前会话可以处理新消息和符合条件的未回复消息，不会逐条补发全部历史消息。
- [ ] 简历请求仅作用于目标会话；附件和提示正确。
- [ ] 联系方式交换、明确面试安排、地点接受、薪资/到岗/录用/合同承诺会在模型回复前暂停当前岗位会话。
- [ ] 普通薪资/地点介绍、期望薪资询问、面试流程介绍、否定地点条件、明确拒绝/系统消息和招聘广告，不仅因关键词而触发上述人工暂停。
- [ ] “扫码进群领取资料”“扫码进群获取资料”“注册充值后安排推广任务”“邀请好友返佣”等营销引流消息默认不自动回复。
- [ ] “缴纳入会费后开始接单”等收费消息，即使打开营销自动回复偏好也不会调用 AI；“退还历史入会费”等正常岗位工作内容不会只因“入会费”字样被拦截。
- [ ] “招聘市场推广专员，负责品牌内容和活动执行”等正常岗位描述不会仅因出现“推广”而静默。
- [ ] “岗位职责包括推广活动，扫码进群后每日签到和录入门店客户资料”等工作流程描述不会仅因扫码、注册词而静默。
- [ ] “岗位职责：负责课程推广，指导用户注册后完成门店资料录入”等工作流程不会被误判成要求求职者参加营销引流。
- [ ] “岗位不涉及培训贷另有押金”等前面有否定、后面另列风险的消息仍会被硬风险规则拦截。
- [ ] “售后客服处理用户充值不到账和退款咨询”等正常客服职责不会仅因“充值”一词被硬风险规则拦截。
- [ ] 打开“营销推广类消息自动回复”后，普通营销消息可以进入 AI，但收费、刷单、拉人头、账号交易等硬风险仍不自动回复。
- [ ] 宣传材料不声称“回复越多就会获得更多 HR 消息”或“不会被平台限制”。
- [ ] 图片、卡片、链接等无法可靠理解时提示或交还人工。
- [ ] 切换账号后旧账号的简历、偏好、坐席及缓存不被复用。
- [ ] 邮件已配置时可收到脱敏提醒；未配置时状态不伪装成功。

## 发布候选代码回归

- [ ] 自定义模型端点拒绝 HTTP（除非自部署明确启用例外）、环回/私网地址、URL 凭据、查询参数和绝对接口路径。
- [ ] DNS 解析返回任一非公网地址时拒绝连接；模型端点 30x 响应不会被跟随。
- [ ] 用户超时值被约束在 1 至 120 秒，超大或分块模型响应在 2 MiB 处终止。
- [ ] 重复导入简历会更新唯一记录，不发生逻辑删除后唯一键冲突。
- [ ] 用户配置查询只返回 API Key 是否已配置，不返回密钥原文。
- [ ] 登录、简历导入、模型配置测试和主要 AI 请求触发应用级限速；模型并发超过配置上限时收到 429。
- [ ] 新版浏览器脚本短暂连接到尚未更新营销闸门的服务端时，默认关闭仍会在浏览器本地拦下明确营销消息，不发送 AI 请求。
