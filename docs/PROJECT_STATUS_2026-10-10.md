## 本地候选修复

- 用户自定义模型 URL 拒绝凭据、查询/片段、非 HTTPS（除自部署显式启用外）、环回/私网 IP；连接时再校验 DNS 结果，并禁用重定向。
- 用户模型超时限制到 1 至 120 秒，模型响应上限 2 MiB。
- 简历文件解析客户端改为使用相同的超时、响应大小和端点策略。
- 简历重复导入改为更新用户的唯一简历记录，避免“逻辑删除后插入”撞 `user_id` 唯一键。
- 当前用户的模型配置查询不再返回 API Key 原文，只返回是否已配置。
- 密钥配置留空默认保留已保存的 Key；只有请求显式带 `clearApiKey=true` 才清除。
- 登录、简历导入、模型配置测试、岗位筛选、岗位化招呼和 AI 对话增加单实例限频与并发上限。
- 免登录登录/导入入口另有独立于请求 UID 的全局限速，避免通过更换 UID 绕过身份桶。

这些代码改动都只在本地工作区。应用限速不是分布式限流或每日费用上限；管理员配置的代理型全局模型池不会经过应用内目标 IP 检查，私网防护仍需可信代理和生产网络出口规则兜底。简历关联数据删除、备份/日志留存和模型供应商副本都没有因此解决。
